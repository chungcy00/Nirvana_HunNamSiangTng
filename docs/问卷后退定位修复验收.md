# 问卷后退定位修复验收

2026-10-23。仅修正返回问卷结果时的滚动时机，未修改正式产品资料、数据库、图片、卡片、字体、配色或样式。CSS 仍为 `assets/index-DvXrRKQF.css`。

## 原因与处理

浏览器后退时，布局的路由效果会在公开产品复核完成前读取并清除返回标记。此时原结果卡片尚未重新出现，原有问卷效果又只处理 URL 中的产品结果锚点，未处理从普通问卷锚点后退的标记，导致最终位置受原生历史滚动恢复影响。

现在问卷在渲染时捕获一次性的返回目标，等待公开资料读取完成、结果重新渲染，再在两次动画帧后定位。沿用现有 `scroll-margin-top: 112px`，无需更改页头或卡片尺寸。浏览器后退用即时定位；“返回问卷结果”链接继续遵循现有 CSS 滚动行为。问卷答题时的平滑滚动和减少动态效果设置保持原样。

同一次导航完成定位后不因后台刷新再次抢走滚动位置；离开页面会取消未执行的定位。若原产品已不再公开，定位到当前结果区，不从旧快照恢复产品。

## 验证

使用本地独立 HTTP 测试资料，测试类别为火化土葬／佛教／双人／预算未定，加入一个独立测试产品。资料读取人为延迟 900ms，以覆盖先返回、后出现结果卡片的情况。没有使用或修改正式产品，没有发送 WhatsApp 或联系表单。

| 产品读取期间后退 | 读取完成后再定位，答案、已选产品保留 |

| 定位任务取消 | 离开路由时取消第一或第二帧的待执行任务，测试通过 |

95/95 测试通过；类型检查、正式构建、页面拆分和提前请求检查通过。源码变更不涉及推荐规则、会话格式或公开产品读写规则。新增调度测试验证不会提前滚动、焦点不会产生二次滚动、离开路由取消操作，以及显式链接保持 CSS 配置行为。
