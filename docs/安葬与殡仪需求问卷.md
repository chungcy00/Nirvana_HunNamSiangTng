## 1. 目的与范围

帮助访客整理需求、浏览相关服务，并将选择带入顾问咨询。采用展开式设计，流程为：

**服务方向 → 宗教信仰 → 使用人数（仅安葬）→ 使用情况 → 预算 → 展示服务 → 联系顾问**

- 安葬范围：骨灰位安置、火化后骨灰土葬、传统土葬，仅展示富贵山庄。
- 殡仪范围：富贵山庄殡仪配套，以及云南善堂单一 RM8,800 殡仪配套。
- 不包含单独火化服务、神主灵位、生基或宠物纪念。
- 不询问骨灰位、火化或土葬偏好，不将问卷结果视为正式预约、购买或最终报价。

## 2. 页面文案与题目

标题：**了解您的需求**

说明：简单选择，了解您希望安排的服务，再与顾问进一步沟通。

以下选项均为单选，初始不预选答案。题目按实际显示顺序连续编号，安葬共5题，殡仪共4题。

| 题目 | 选项 | 显示规则 |
|---|---|---|
| 您想了解哪方面的服务？ | 安葬安排／殡仪服务 | 始终显示 |
| 您的宗教信仰是？ | 佛教／基督教／其他 | 始终显示；不增加其他选项或补充输入框 |
| 您希望了解几人使用的安置空间？ | 单人／双人／或以上 | 仅选择安葬时显示；「或以上」代表三人及以上 |
| 您目前属于哪种情况？ | 提前规划／目前需要安排／先了解，尚未确定 | 始终显示 |
| 您希望考虑的预算范围？ | 按服务方向显示下表选项 | 未选方向时保留题目，提示先选择服务方向 |

使用人数指安置空间容量，不代表已包含对应人数的全部火化、安葬或殡仪费用。

选择「目前需要安排」时，在该题下显示顾问电话联系入口，同时允许继续填写。

## 4. 服务结果规则

### 4.1 展示时机

结果区域始终保留。尚未回答所有适用题目时，提示「完成以上选择，即可查看相关服务」。选择「先了解，尚未确定」或「预算未定，先了解」均算已回答。

顾问直接联系入口不受完成问卷限制。

### 4.2 安葬分支

- 只展示富贵山庄，依据宗教、空间容量与预算筛选。
- 不按安葬方式筛选；符合条件的骨灰位、火化后骨灰土葬和传统土葬产品都可出现。
- 产品标明上述所属大类。单人对应单人空间，双人对应双人空间，「或以上」对应三人及以上空间或家庭福地。
- 容量或宗教适用范围不明确的产品列入「需咨询确认」，不视为已匹配。

### 4.3 殡仪分支

- 分为「富贵山庄」「云南善堂」两个机构区块，按宗教、使用情况和预算展示。
- 不按火化或土葬筛选，因此富贵自由可以出现，但必须显著注明「仅限火化」。
- 富贵山庄选择「提前规划」时展示预购参考价；「目前需要安排」时展示即时参考价；「先了解，尚未确定」时同时展示两种价格。
- 尚未确定使用情况且两种价格都展示时，任一种价格落入预算区间即可列出，并明确标示哪一种符合预算。不能用预购价暗示即时费用。
- 预购价格适用条件须由顾问确认，不能仅凭「提前规划」保证可享预购价。
- 云南善堂保持单一 RM8,800 配套，不拆分预购与即时产品。按用户提供的信息，佛教及基督教均适用，具体仪式按客户需求调整。
- 云南善堂属于殡仪服务，其适用性不受火化或土葬方式限制；不据此推断配套已包含火化费用、墓地、骨灰位或其他安葬费用。
- 富贵山庄殡仪卡片说明其不包含火化费用、墓地或骨灰位等安葬项目。

### 4.4 宗教与预算的共同规则

- 「其他」显示相关服务供了解，统一注明「宗教及仪式适用情况需咨询确认」，不视为已匹配。
- 佛教或基督教结果中，适用宗教已明确的产品按资料匹配；宗教资料缺失的另列「需咨询确认」。
- 产品有多个价位时，只要对应款式有一个价格落入预算区间即可展示，并指出符合预算的款式与价格，不用最低价暗示全部位置同价。
- 地段价和配套价独立标注；筛选命中地段价时明确提醒其不是完整配套费用。
- 价格缺失的产品可列入「需咨询确认」，不能当作预算内产品，也不能因缺少价格被完全隐藏。
- 参考价格不等于实时售价；历史销售图与售罄标记不作为当前库存证明，供应情况需确认。

## 5. 产品卡与联系

产品卡包含：机构、产品名称、安葬大类或殡仪类别、简短说明、具体参考价格、资料已明确的包含内容、适用限制及供应确认说明。

操作为「查看详情」及「加入咨询」，支持多选，再次操作可取消。没有产品照片时不以虚构图片暗示真实产品外观。

没有匹配结果时显示：

> 目前没有找到符合全部条件的资料，您可以放宽预算、查看其他选择，或直接与顾问沟通。

- 「放宽预算」：将预算改为「预算未定，先了解」，保留其他答案。
- 「查看其他选择」：临时展示当前服务方向内的全部相关产品，标注它们可能不符合当前条件；再次修改答案时恢复筛选。该模式及标签加入咨询摘要，避免误认为产品已匹配。
- 「联系顾问」：即使未选择产品也可使用。

咨询摘要包含：服务方向、宗教、安葬人数（仅适用时）、使用情况、预算，以及感兴趣的产品。未回答的内容标注「尚未填写」，不代填。

联系操作：

- **通过 WhatsApp 咨询**：将摘要带入消息，由客户确认发送，不自动发送。
- **将结果带入咨询表单**：将摘要带入现有咨询内容，避免客户重复输入；称呼及电话在咨询表单内填写。

本需求不要求在问卷内重复收集姓名、电话、住址或身份证资料。

## 6. 展开式交互

- 适用题目与已选答案保持可见，不逐题跳转，不自动收起，不强制滚动。
- 更改服务方向时，清除安葬人数、预算及已选产品，保留宗教与使用情况；切回安葬后人数需重新选择。
- 更改宗教、人数、使用情况或预算后，保留仍适用的产品选择，清除不再适用或无法继续确认匹配的选择，并提示「部分已选服务因条件变化已取消，请重新确认」。
- 仅修改答案但没有取消产品时，不显示取消提示。
- 选中状态不能只靠颜色区分；选项支持键盘操作及清晰焦点，手机端方便点击。
