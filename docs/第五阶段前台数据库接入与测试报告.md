## 接入范围

`src/catalog/publicRepository.ts` 只调用现有 `api.catalog_product_list` 与 `api.catalog_product_detail`，列表和详情所含价格仍由既有 `catalog_product_prices` 及 RLS 控制。这三项 RPC 的真实云端 owner 已复核为受限的 `fg_catalog_reader`。没有增加表、字段、函数或权限。

`PublicCatalogProvider` 统一供产品列表、详情和问卷使用：最多四个并发详情读取，保留 RPC 返回的默认排序，页面导航、窗口重新激活及可见页面每 60 秒重新读取。请求使用 no-store，不持久化产品快照。超时、配置错误、网络失败及详情已撤回时均不退回静态数据；加载、错误重试、正常空目录和无此产品分别处理。

沿用当前页面组件、七大类别、人数／宗教筛选、排序图标、网格／列表切换、整卡点击、最低起价和详情布局。公开数据里的完整价格、宗教包含项目及设计图继续在详情中展示；殡仪服务保留预购及即用价格。旧 `/nirvana/packages/:slug` 进入同一公开详情，旧类别地址返回公开目录。原型样本不再作为公开路由提供；固定样本仅用于隔离测试，未进入生产构建。

图片使用匿名公开身份请求现有 private Storage 的 authenticated 下载接口，再显示为受控内存 Blob；不把 bucket 改为 public，不生成可绕过后续权限检查的签名 URL。每次下载仍由现有 Storage 规则校验产品、宗教和图片状态，组件卸载时取消请求并回收 Blob。

问卷保留原有分支、预算筛选、加入咨询、详情跳转、返回恢复和 WhatsApp 摘要。价格区间及推荐清单改由当前公开产品计算；隐藏或撤回的已选项目不会带入咨询摘要。浏览器会话只保存答案与所选标识，产品重新加载后再次核对，未保存价格或权限快照。

室内／室外字段仍未获批准且实际不存在，因此本阶段不根据名称或旧样本推断环境标签；待审迁移保持未执行。现有数据库公开接口未提供的细项不从 HTML 或静态表补值。
