# 销售状态与部分售罄

产品、价格方案和设计图片分别保存 sale_status（available / sold_out），与发布、启用、图片批准公开保持独立。

## 后台操作

- 基本资料 → 产品销售状态：整件产品设为「已售罄」，即使仍为已发布，前台目录、详情和公开价格 RPC 也不返回它。改回「在售」可恢复，无须重新录入图片或价格。
- 价格 → 方案销售状态：仅标记该方案售罄，前台详情仍保留该公开方案及价格，并显示「已售罄」。
- 图片管理 → 宗教与设计参考 → 设计销售状态：保留售罄设计照片并显示「已售罄」，仍可放大参考。同宗教、同名设计的照片由编辑器同步；未命名设计逐张独立设置。
- 部分售罄时，产品总状态保持「在售」。产品总状态优先，设计与方案之间没有虚构关联，也不按照片数量自动推断整件产品售罄。
- 三个层级都需保存后生效；未启用方案、未批准价格／图片仍遵守原有公开规则。预览「拟公开内容」会明确提示整件已售罄；「后台全部配置」仍可查看。

前台卡片起价和问卷推荐仅取在售方案，避免把便宜但已售罄的方案当作当前报价。详情保留已售罄方案作参考，照片不去色、不删除。

## 数据与权限

增量迁移 20261027120000_catalog_sale_status.sql（云端版本 20261027020211）。现有 20 件产品、28 个方案、8 张图片默认保持在售，未替用户判断库存、未变更发布状态。公开可见性由 private.public_product 统一约束，原有 fg_catalog_reader 身份、空 search_path、RPC 白名单和媒体权限边界保持不变。

沿用前台 30 秒标签页快照和后台重读：已打开页面在下一次成功同步后更新状态，失败会清除旧数据。没有加入长时间 CDN 产品缓存。
