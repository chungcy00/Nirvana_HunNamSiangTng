# 第一阶段：正式后台开发与测试报告

完成日期：2026-10-22（Asia/Kuching）。本报告只验收第一阶段，不代表完成第二阶段真实管理员登录验收、第四阶段双平台部署或第五阶段前台数据库切换。

## 已完成范围

新增独立应用 `apps/admin`，沿用用户提供的《富贵山庄_后台产品管理_交互样本.html》黑白交互：深色导航、产品列表、七类动态编辑表单、逐类别独立排序、园区／系列和宗教快速新增、图片上传／替换／主图／排序、私有及限制访问、方案与价格、预览、发布确认、隐藏、复制、审计与设置。云南善堂只保留占位页面。桌面、平板和手机保持原型布局规则，手机操作区按正常文档流显示。

正式业务已接实际 Supabase Auth、RPC、私有 Storage 及事务，不依赖 HTML 演示账户、模拟权限、localStorage 产品资料或模拟保存。浏览器只保留 SDK 的实际登录会话；成员身份从数据库读取。编辑员与管理员按钮及保存能力遵循已有权限边界，服务端也验证身份。

保存只提交允许字段和实际变更。版本冲突返回 409 并保留表单，支持重新读取和下载未保存资料。发布沿用已确认的数据验证；类别排序检查完整产品集合和各自版本，一次提交事务。复制创建新草稿与独立文件路径，清除内部编号／备注／来源并取消公开批准，失败补偿清理文件。图片删除有数据库引用保护，阻止检查后新增引用的竞争。

室内／室外的待审迁移 **未执行**，后台不写入 `placement_type`，显示暂未开放编辑。前台页面、问卷与现有正式产品内容未改动。

## 安全与交付边界

高权限密钥只用于服务端文件复制／清理。接口先验证真实用户及有效管理员／编辑员资格，产品保存使用调用者身份。图片引用保护在数据库层执行，服务端高权限也不能删除已引用图片；清理仅接受受控 bucket 与合法路径。无自助注册、模拟角色开关或绕过登录入口。

上传失败、保存失败、过期会话、并发冲突都有实际错误反馈。未保存文件在放弃／成功保存后尝试清理，失败可维护重试；第一阶段没有启用远端定时清理任务。

当前可以在本地后台实际测试，Vercel 部署结构已准备。**没有建立新的正式部署，没有切换 前后台 域名，没有删除旧前台，也没有修改正式 Auth 回调配置。**

第一阶段完成后停在此处。下一阶段按计划验证真实管理员账号、正式环境登录与回调、角色／RLS／Storage 限制；第三阶段再在隔离测试资料上完成指定产品完整流程验收，不能将本阶段本地通过等同于正式环境全流程通过。
