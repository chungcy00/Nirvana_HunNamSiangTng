# 前台 v1.2 视觉改造与殡仪无照片验收

2026-10-23（Asia/Kuching）。唯一有效 UI 基线为 [前台网站视觉规范与 UIUX 优化需求文档 v1.2](前台网站视觉规范与UIUX优化需求文档.md)。原下载目录文件及项目中的《设计规范与界面改造需求文档》已移入废纸篓，原聊天内容无法由项目工具删除；不再作为需求依据。上一轮中断前没有执行旧 UI 改造。

## 实际范围

- 保持原字体家族、加载方式、回退、字重和整体字阶。四份原 CSS 的字体声明逐项对照相同；没有新字体或 CDN。
- 前台颜色收敛至 src/styles/tokens.css，主色黛绿、克制金色点缀，正文与价格维持可读的深色。较小金色文字使用满足对比度的衍生色；透明覆盖层保留。
- 按钮、卡片、占位图、标签、Tab、筛选、网格／列表控件统一边框、留白、圆角、焦点和选中态；分类仍单行横滑、当前项自动滚入可见范围，保留排序与筛选逻辑。
- 网格图片参考 16:9、详情 3:2，手机左图右文模式保留原 1:1 列以容纳内容。占位使用中性类别名和 Lucide 线条，不生成假实景；首页两个既有入口使用不同中性意象。
- 维持页面信息架构与内容顺序，没有新增热门产品、资质／信任区、FAQ、付款条款、分期、每卡咨询按钮或强制浮动咨询。
- 联系表单仍直接跳转 WhatsApp，没有预览中间步骤；电话格式错误就地显示，提交后说明内容已准备并须在 WhatsApp 内由用户发送。问卷顺序、分支及消息组装不变。
- 云南善堂仅优化既有页面；修复其平板图片占位撑出页面的问题，没有新增分类或产品。

## 殡仪服务完全无照片

这是用户单独第 1 条业务指令，独立于 UI 文档范围。已移除后台“图片管理”导航、宗教配置中的图片入口、后台图片预览；前台殡仪卡片图片位和详情画廊完全不渲染。公开投影也忽略该类图片字段。其他类别仍可使用图片。

新增迁移 20261022160606_funeral_without_media.sql，远端版本 20261022160726：殡仪服务草稿与发布均拒绝照片引用，保留此前无需主图的规则；没有增加表或字段。函数所有者和执行边界不变，现有 18 表数据数量与摘要完全一致，原有 20 件产品未修改或发布。其他类别主图要求、宗教、价格和发布权限不变。

殡仪网格及列表均按新版文档展示预购和即用双价；其他类别保留原卡片起价与详情多方案价格。价格备注使用“以上价格未包含印花税”，其他真实产品备注保留，不增加税额或税率。

## 路由与部署核对

现行富贵山庄详情路由为 /nirvana/products/item/:productId，实际使用 PrototypeDetail；旧 /nirvana/packages/:slug 重定向到该路由。PackageDetail 是保留的通用机构模板，不能据其含咨询按钮就断言现行页面漏部署。改造前线上产物与仓库基线一致，未证实部署缺失；本次依 v1.2 不增设额外 CTA，原导航咨询及联系路径保留。

仍沿用用户已确认的 Vercel 前后台与新域名，不恢复已删除的测试托管项目。本 UI 文档中的部署描述不构成重新迁移托管的授权。

## 验收结果与边界

- 前台 75 项、后台 13 项单元测试通过；前后台构建及类型检查通过。后台 CSS 未修改，保持黑白灰主题。
- 独立本地真实 Supabase 12 项测试通过，包括实际测试 PNG 上传后附加到殡仪草稿被拒绝、无照片发布及公开读取、价格／宗教缺项回滚、隐藏，以及其他六类无主图仍不准发布。没有云端测试产品写入。
- 浏览器 21 组布局检查覆盖首页、目录、殡仪列表、普通与殡仪详情、联系、云南善堂，390／768／1440 外框宽度下均无页面横向溢出。实际内容宽度扣除了浏览器滚动条，详见结果 JSON。
- 手机菜单打开后的遮罩、焦点、关闭并回到触发器已核对；联系表单错误显示已核对，没有发送消息。
- 7 组主要文字／背景配对达到 AA，对全站所有叠加图像和每个像素不作无限范围保证。机械检测无发现；缩减动效沿用并覆盖新增过渡。
- 性能记录来自本地开发服务器与当前浏览器，没有模拟 4G。CLS 样本 0；当前浏览器未提供 LCP 条目，因此不把 0 当作 LCP 耗时，更不宣称线上 4G 达标。生产 JS gzip 约 117KB、CSS gzip 约 17KB，无新增字体请求。
