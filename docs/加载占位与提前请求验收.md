# 加载占位与提前请求验收

2026-10-23；正式实现提交 `2f40639`、`7cf0a3f`，已部署至 https://nirvana-hnst.vercel.app/ 。未修改数据库、产品资料、公开读取条件或后台。

## 实施内容

1. 页面模块加载提示、产品资料初始加载提示预留至少一个小视口高度，避免加载时页脚提前进入首屏，随后被内容推走。占位只在加载时生效，完成后的高度与样式保持原样；失败提示和重试功能保留。
2. 构建时从实际输出解析当前路由模块及依赖，用带哈希的真实地址提前请求；不预加载其他页面，不下载其他页面的主图。首页只提前请求与现有 picture 规则匹配的一张原图，优先级 high；先解析 viewport 再判断媒体条件。未改图片编码、尺寸、路径、卡片、字体、颜色、CSS 顺序或动效。

最终 CSS 仍为 `assets/index-DvXrRKQF.css`，与优化前完全一致。图片文件和 Home 组件无差异。

## 手机模拟低速 4G 对比

同一 PageSpeed Insights 服务，手机 Moto G Power 模拟环境、Lighthouse 13.5.0、HeadlessChromium 153.0.8010.36、低速 4G、初始网页加载。基线报告时间 GMT+8 01:41–01:42；优化中两轮 01:49–01:50，最终实现另作一次确认。下表的优化后数据只取最终版本确认报告；基线为之前两次报告的范围。

| 页面 | 优化前 LCP | 最终确认 LCP | 优化前 CLS | 最终确认 CLS |
| --- | --- | --- | --- | --- |
| 首页 | 3.8–4.1 秒 | 3.9 秒 | 0–0.683 | 0 |
| 富贵山庄 | 1.5 秒 | 2.4 秒 | 0.530 | 0 |
| 联系代理 | 3.6 秒 | 2.0 秒 | 0.683 | 0 |

最终三页 FCP 均约 1.5 秒，TBT 显示 0 毫秒。优化中的两轮结果：LCP 首页 3.9 秒、产品页 2.1 秒、联系页 2.1 秒；CLS 分别 0、0.022、0。该结果用于辅助观察，不与最终版本合并计算统计值。

### 结论及限制

- 原先的大幅页脚位移在最终确认中未再出现，三页 CLS 均为 0；这不保证所有设备、网络、后续交互或长时间运行都没有位移。
- 联系页 LCP 从 3.6 秒降至 2.0 秒，约缩短 1.6 秒；候选仍是联系页标题。
- 首页 LCP 3.9 秒落在原有 3.8–4.1 秒范围内，**不能声称明显提速**。提前请求已经生效，原图保持不变，尚未达到良好 LCP 目标。诊断追踪中仍有元素渲染延迟，追踪分项不可直接等同模拟总 LCP；未擅自修改现有动效或图片。
- 产品页 LCP 从 1.5 秒变成 2.4 秒，数值上增加约 0.9 秒。优化前 LCP 候选是提前露出的页脚免责声明；最终候选是目录空态说明，测量对象发生变化，不能用这两个数值直接断言产品读取变慢或加快。当前公开分类无产品，未将其当成有实拍商品卡片的加载测试，也没有为测试而发布资料。
- PageSpeed 没有该站真实用户数据；这是有限实验室样本，不是现场用户第 75 百分位。未手动预热浏览器缓存，缓存和模拟由 PageSpeed 管理，CDN 状态未逐次控制。没有拿普通网络下的浏览器预览当作 4G 数字。

良好参考为 [LCP ≤2.5 秒](https://web.dev/articles/lcp)、[CLS ≤0.1](https://web.dev/articles/cls)。
