# 按页面分批加载验收

2026-10-23。仅调整前台页面代码的加载方式，未修改数据库、正式产品、图片文件、卡片、字体、配色或动效。

## 加载范围

- 首页、联系页（含问卷）、关于服务、云南善堂、通用机构／分类／配套页面采用独立按需分包。富贵山庄目录与详情共用产品功能分包，避免重复代码。
- 导航与页脚保留在公共布局；页面读取中提供现有样式的加载提示，分包失败提供重新载入入口。
- 页面载入后再执行标题、哈希定位及问卷返回定位；公共咨询控件重新测量异步出现的内容，避免按空白页面的位置处理。
- CSS 保持原加载顺序并继续预先加载，不拆分样式；生产文件仍为 `index-DvXrRKQF.css`，与改造前一致。未增添字体请求，未改图片加载或文件。
- 原有产品公开读取、刷新与失败清空规则未改；测试使用只读公开数据或独立样例，没有保存、发布或隐藏正式产品。

## 包体积

使用同一 gzip 算法计算生产 JS 文件，包含所需静态依赖、去除重复共享文件；不是网络耗时或首屏指标。

首页所需脚本减少约 11%。CSS 和图片不计入这些 JS 数字；没有把脚本缩减比例宣称为实际加载时间提升。

## 验证结果

- 91 项测试通过，包括原有渲染、筛选、详情、问卷、公开读取与刷新测试，以及七条实际 lazy 路由的异步渲染验证。静态 SSR 断言复用同一份路由映射，另有真实 lazy 路由测试，未用测试标记改变生产行为。
- 类型检查、生产构建和构建依赖图检查通过。首页依赖不含联系页、产品页和关于服务的分包。
- 本地生产构建浏览器：直接打开首页、联系页问卷锚点、关于服务、云南善堂和富贵山庄正常；问卷锚点位于约 112px 的既有顶部留白处。
- 浏览器 DOM 中首页只出现首页及其共享依赖的 modulepreload；点击联系代理后才出现 Contact 分包。问卷选择殡仪后宗教问题启用，后续分支正常；没有发送 WhatsApp 消息。
- 手机独立样例：菜单跳转到关于服务后关闭，页面无横向溢出。
- 旧配套链接仍重定向到现行详情路由；不存在的产品显示既有未找到页面。
- 临时移走本地预览构建的 Contact 文件，验证失败提示与重试入口；恢复该构建文件后点击重新载入，联系页恢复。故障仅在独立本地预览中模拟，文件已恢复，没有影响线上。

未进行实体手机、4G 网络或 LCP／CLS 测试。线上发布产物和新分包缓存响应头在部署后核对。
