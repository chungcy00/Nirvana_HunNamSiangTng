# 通用与目录组件拆分验收

2026-10-23；基线 `f80b2f3`，实现 `6e2961e`，已部署 https://nirvana-hnst.vercel.app/ 。仅移动组件并调整引用，没有修改正式产品资料、数据库或权限规则。

## 拆分内容

- `src/components/ui.tsx` 保留通用咨询按钮、区块标题、联系入口和找不到页面提示。
- 通用 `PageHero`、`Placeholder` 各自独立，使用页面按需加载。
- `src/components/catalog/ui.tsx` 放置目录专用产品卡片、面包屑与价格显示工具，不再从通用文件反向导出。
- 调整引用这些组件的页面和两份现有测试的导入路径。目录 Provider 及公开刷新生命周期不变，没有顺带执行第三项优化。

9 个组件／辅助函数的函数体逐字保持一致。图片文件、卡片 JSX、字体、配色、动效及样式均没有变化。CSS 仍为 `assets/index-DvXrRKQF.css`。

## 验证

- 95/95 测试通过；类型检查、生产构建、页面拆分、预加载检查通过。
- 拆分前后，对首页、联系页、关于页、云南善堂页、七类目录、产品详情、旧目录与详情等共93个页面／测试资料场景渲染，HTML输出全部逐字一致。
- 目录卡片专用文案不再进入公共入口；首页也未预加载目录专用组件。
- 独立本地 HTTP 测试资料：两个火化土葬产品、一个骨灰位产品，未连接或写入正式数据库。
- 手动浏览器验证：首页导航、关于页、云南善堂页的通用页头和占位图正常；目录价格降序结果为 AA区、W区；切换列表模式正常；筛选基督教只剩 W区；详情链接及后退保留筛选、排序和列表模式。
- 问卷选择火化土葬／佛教／双人／预算未定，加入 W区咨询；刷新后恢复答案和已选产品。从详情后退，卡片顶部约111.94px，页头底部89px，原定位修复保持有效。
- 上述交互检查实际在桌面宽度1063／1280px完成；手机加载指标来自以下Lighthouse模拟，不将其等同于完整真机触控验收。未发送WhatsApp或提交联系表单。
