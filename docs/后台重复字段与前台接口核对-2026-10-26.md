# 后台重复字段与前台接口核对

日期：2026-10-26。范围：七类产品的编辑字段、保存载荷、公开 RPC、前台投影、未保存预览和详情展示。

## 确认的问题与修复

| 项目 | 原问题 | 当前处理 |
| --- | --- | --- |
| Zone AA 朝向、面积 | 共通与默认方案实际相同，后台同时要求管理员理解两套输入 | 共通规格只填一次；价格页显示继承摘要，只有不同的方案才展开填写 |
| Zone W 多方案面积 | 方案有真实面积差异，公开价格接口却未返回 | 保留差异；接口新增方案面积、朝向、位置类型，与对应售价一同显示 |
| 修改共通规格 | 旧的重复方案值会变成过期的覆盖值 | 编辑共通规格时，将与旧共通值相等的覆盖值改为继承；真正不同的覆盖值保留。仅在管理员保存时写入 |
| 固定人数 | 单人、双人、三人既有分组又能手填人数 | 固定人数自动确定；家庭及四人以上才显示实际人数输入 |
| 其他类别属性 | 部分字段已保存，但未投影到详情 | 增加明确的类别白名单，显示长度、宽度、牌位类型/容量、生基类型、宠物规格/安葬类型等；骨灰瓮与火化只在包含项目维护和展示 |
| 补充说明 | 安葬、骨灰位款式、牌位、生基、宠物说明未展示 | 以对应名称展示已填写的说明；不推断内容，不显示内部备注和来源 |
| 宗教配置 | 配置标题/说明可填，但公开接口及预览丢弃 | 非殡仪类别补齐接口和映射；殡仪历史旧配置继续隐藏 |
| 图片分类与主图 | 核查是否还有分类与主图设置重复 | 当前已分为实景相册/设计参考；主图由勾选决定，保留当前分组方式 |
| 两层价格备注 | 管理者不清楚是否两处都要填 | 共通备注只填一次；某个价格的独立条件留在该价格下，保留既有独立来源规则 |

## 核对七类

火化土葬、传统土葬使用共通规格与可选方案差异；骨灰位只显示人数、环境及主题/款式说明，继续不显示朝向/面积。殡仪保持服务天夜数、安葬方式与服务地点，不恢复旧宗教配置或照片。祖先牌位、生基风水、宠物安葬补齐现有可编辑属性和说明。

宗教关联与图片/价格的适用宗教、产品名与宗教配置标题、产品简介与类别补充说明属于不同内容范围，不能删除或自动合并。面积和长宽也不是重复字段：不假设地段一定是规则矩形，不擅自计算覆盖已填写的面积。

## 包含项目归属修正

按用户标注，骨灰瓮数量与火化次数不属于顶部类别规格。移除类别专属属性中的这两个重复入口，前台顶部也不再投影它们。骨灰瓮/盒和火化服务统一在包含项目的名称、数量、单位维护，详情与预览只显示包含项目中的条目。Zone AA 已有“骨灰瓮及盒 × 2”和“双人火化费”，原文及数据库旧属性值均保留，部署不迁移、不清空、不改写产品数据。
