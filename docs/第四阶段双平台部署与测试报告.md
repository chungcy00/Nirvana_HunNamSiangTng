## 修复和配置

Cloudflare 默认 Bun 1.2.15 无法读取仓库已有锁文件，首次构建失败；将构建环境的 `BUN_VERSION` 设为 1.4.4 后构建成功。没有改写锁文件或升级依赖。保留 Pages 默认 SPA 回退，深层路由可返回应用。

Vercel 首次部署显示 Ready，但图片接口实际返回 500。运行日志确认 Node ESM 无法解析无扩展名的 `../server/media`。两个 API 入口改为 `../server/media.js` 后重新部署，真实接口测试通过。没有把本地模拟服务器结果当作线上函数验收。

后台环境变量：`VITE_SUPABASE_URL`、`VITE_SUPABASE_PUBLISHABLE_KEY`、`VITE_AUTH_VERIFICATION_ONLY=false`、`SUPABASE_URL`、`SUPABASE_PUBLISHABLE_KEY`。`SUPABASE_SERVICE_ROLE_KEY` 按用户授权仅保存于新后台项目的 Production Secret 变量，不带 VITE 前缀。该高权限密钥未配置到 Cloudflare 或原 Vercel 前台。

后台所有页面配置 noindex、nosniff、no-referrer。Cloudflare 测试前台通过 `public/_headers` 配置 noindex、nosniff 和 strict-origin-when-cross-origin；正式上线前需复核是否移除测试 noindex。
