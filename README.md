# 身后规划服务网站

面向电脑、平板和手机的响应式用户端网页框架。沿用 React、Vite、TypeScript、React Router 与 Bun，不需要数据库或 API 密钥即可运行。

按分享对话的最后方案组织：个人顾问首页 → 服务入口 → 富贵山庄六大类别 → 分类筛选 → 产品详情 → 咨询。

## 启动与检查

```sh
bun install --frozen-lockfile
bun run dev
```

没有安装 Bun 时，也可以运行 `npm exec --yes --package=bun -- bun install --frozen-lockfile`，然后 `npm run dev`。默认预览端口为 3000，以启动输出的实际地址为准。

```sh
npm run lint
npm run build
```

构建产物在 `dist/`，可部署到支持 SPA 路由回退的静态网站托管。`vercel.json` 已预留 Vercel 页面刷新回退配置。

## 后续填入资料的位置

- `src/data/site.ts`：顾问姓名、代理编号、经历、语言、电话、WhatsApp、邮箱、服务时间。WhatsApp 填国际格式数字，例如马来西亚号码以 `60` 开头；请填写顾问自己的真实号码。
- `src/data/catalog.ts`：六大类别、29 个产品条目、已核对价格，以及可选的区域、面积、方向、分期、服务阶段字段。
- `src/components/ui.tsx` 的 `Placeholder`：统一图片预留组件。后续用自有或获得授权的图片替换。
- `src/components/layout/Navbar.tsx` 的 `Brand`：页首与页尾共用的 Logo 预留。
- `src/index.css`：米白、深绿、柔金配色及响应式布局。主要断点为 1100、960、640 像素。

当前没有下载、截取、嵌入或热链任何第三方产品图片。没有沿用旧版 Unsplash 照片，也没有使用其他代理的姓名、授权编号或联系方式。个人照片、Logo、产品图、园区图与未确认服务内容均保留位置。

## 咨询行为

未填入有效 WhatsApp 号码时，咨询按钮进入本站联系页，带入产品或服务名称。表单可校验输入、预览和复制咨询文字，但不会发送，也不会显示“已收到留言”。

填入有效 WhatsApp 号码后，咨询链接携带预填文字，用户自行在 WhatsApp 确认发送。联系表单的预览仍不自动发送。输入内容仅保存在当前页面内存中，没有后台提交、浏览器持久化或个人资料日志。

## 资料范围

- 框架依据：内部讨论方案（链接已隐藏）。
- 资料核对日期：2026-09-13。核对了 8 款殡仪配套的生前规划价（Pre-Need）、即时需求价（As-Need），以及 Zone AA 双人火化土葬配套的公开价格与规格。其他价格及详细项目没有猜测填入。
- 云南善堂的实际服务、条件与顾问资格待提供资料确认。本站没有宣称已获得任何机构授权。

本次移除了后台登录占位、Supabase 接线、模拟 API 与假提交成功逻辑，清理了未使用的 Gemini、Express、环境密钥模板及相关依赖。原项目没有原生 Android/iOS、桌面应用、安装包或 PWA 代码；当前保留运行网页所需的代码。
