# 后台界面依据

模式：Operate。以用户提供的黑白 HTML 为准，采用继承还原，不进行视觉方向重设。

| Token | 值 | 用途 |
| --- | --- | --- |
| ink | #171717 | 正文、主操作 |
| muted | #646464 | 次级文字 |
| canvas | #f5f5f5 | 页面背景 |
| paper | #ffffff | 表单、表格、弹窗 |
| line | #dddddd | 分隔线 |
| sidebar | #171717 | 左侧导航 |
| radius | 6px | 用户指定 HTML 的圆角 |
| space | 8px | 基础间距 |
| sidebar-width | 224px | 桌面侧栏；中屏 190px |
| header-height | 72px | 顶栏 |
| content-padding | 32px | 桌面页面留白；中屏 24px、手机 16px |
| body-type | 14px / 1.6 system sans | 操作界面文字 |
| h1-type | 28px / 1.4 | 页面标题；手机 25px |

桌面产品编辑为 184px 分区导航与两列表单；741–1100px 保留侧栏并将编辑字段收为单列，以保证选择框宽度；≤740px 为抽屉侧栏、横向分区导航及单列表单，手机底部操作按原 HTML 使用正常文档流。表格内部横向滚动，不让整页横向溢出。界面保留黑白冷色系，所有产品照片展示原色，不添加灰度或去色滤镜；真实文件无法读取时显示明确的图片状态。

弹窗使用原生 dialog，具有焦点约束、关闭按钮及 Escape。移动侧栏支持 Escape 与键盘焦点约束。控件保持明显焦点、加载、禁用、失败和空数据状态。

获准适配：演示角色、故障开关、占位图添加、演示数据导出／恢复移除；加入真实账号、数据库错误和本地测试库提示。室内／室外只显示暂未开放编辑，不编造数据库持久化结果。源码拆分不改变产品表单分区与主要操作。
